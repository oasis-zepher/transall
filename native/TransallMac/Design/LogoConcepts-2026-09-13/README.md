# Transall 标志概念 · 2026-09-13

三款采用相同的浅色底座、蓝色范围与展示尺寸，仅比较主体造型。此次为概念交付，未修改应用图标资源、界面或产品名称。

## 查看

- `previews/comparison.png`：三款大图、16 / 32 / 64 / 128 像素、单色及深浅背景比较。
- `index.html`：本地浏览页面，可查看逻辑尺寸示例及打开单独的 SVG、PNG。
- `previews/pixel-check.png`：实际 16 / 32 / 64 像素 PNG 和最近邻放大，检查抗锯齿与间隙。
- `previews/monochrome.png`：移除底座、阴影、颜色与材质后的单色正形、反白和小尺寸。

比较图可能被聊天窗口缩小；判断小图时应打开原图，以 100% 比例查看。页面使用 SVG 按逻辑尺寸显示，以适应 Retina 屏幕；像素检查图使用真实低分辨率 PNG。

## 设计评价

以下为基于本轮图像检查的设计判断，并非用户测试结果。

| 维度 | A · 转折 | B · 交接 | C · 重组 |
| --- | --- | --- | --- |
| 主体 | 连续宽带形成紧凑 S 形 | 两个互补圆角形体错位嵌合 | 三片由方到圆、依次错位的薄片 |
| 轮廓易记 | 连续轮廓鲜明，但容易读成字母 S | 两个形体和斜向留白构成独立记忆点 | 由方到圆清楚，但接近常见的堆叠图层符号 |
| 小尺寸 | 16 像素仍保留 S 形，材质变化减弱 | 16 像素仍能分开两个形体，三款中结构最稳定 | 32 像素以上层次更清楚；16 像素对方圆变化的表达最弱 |
| Transall 气质 | 较柔和、有流动感，字母联想与名称首字母不符 | 克制、精确，与上下输入输出的关系呼应 | 最容易联系到文件和格式，略偏通用文档工具 |
| 本轮建议 | 保留为更柔和的备选 | **优先细化** | 保留为强调文件形态变化的备选 |

推荐 B：单色和小尺寸下都不依赖材质表达两个形体的关系，适合目前安静、精确的原生文档工具方向。它仍是抽象标志，需要与 Transall 名称共同建立识别。

## 已完成检查

- 三款均导出可编辑的 1024 × 1024 SVG 和透明边缘 PNG，并提供 16、32、64、128 像素 PNG。
- 实际查看比较图、最近邻像素检查和单色正反形，确认三款主体在去除材质后仍可区分。
- C 的 16、32 像素版本加宽透明层间留白，并随附对应的可编辑 `optical` SVG；其他尺寸使用标准几何。该修正改善分层，但不改变其最小尺寸仍弱于 A、B 的评价。
- 检查深浅背景上的同一浅色底座，不将预览称为系统深色图标变体。
- 未安装图标、未进行 Finder / Dock 实机替换验证；本轮未制作 Dock 模拟截图。

## 文件

每个概念文件夹含 `icon.svg`、`icon-1024.png`、四个小尺寸 PNG，以及 `mono-dark` / `mono-light` 的 SVG、PNG。所有 SVG 使用原生路径、渐变和蒙版，不包含嵌入位图或外部素材。

`build_concepts.py` 用于重建交付文件，依赖 Python、Pillow、resvg-py；中文预览字体使用 macOS 自带的 Hiragino Sans GB，西文字体使用 SF Pro。字体仅用于比较图和网页，图标本身没有文字或字体依赖。

`validation.json` 记录文件结构、尺寸、透明度及引用检查。`Transall-logo-concepts.zip` 是可独立解压查看的交付包。
