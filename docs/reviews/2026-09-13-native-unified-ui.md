# 原生工作区控件统一验收

日期：2026-09-13。范围：轮盘以外的原生界面；未修改处理引擎、任务存储、导出接口或公开 API。工作区已有的轮盘日间配色改动另见同日 light-contrast 记录。

## 实现

- 主操作固定在工具栏右侧，按任务状态显示添加、开始、取消、保存或重新处理；参数栏开关不再移动主操作。
- 参数改为独立滚动的单列原生表单，标签持续可见；PDF 高级选项分组，翻译外发提示直接可见。
- 移除参数底部及空预览的重复主按钮；轮盘下方的重复文件按钮改为提示，保留原有布局尺寸。设置通过标准 App 菜单和 `⌘,` 打开。
- 文件移除按钮按悬停/选中显示，并保留上下文菜单、键盘和辅助功能入口。
- 对照区小于 600 点时上下排列；每份文档保留自己的搜索、翻页和缩放。窄窗口默认收起参数栏。
- 设置分为翻译服务、Office 转换、数据与隐私，保存固定在底部；保留原有密钥恢复和删除保护。
