# 固定工具栏与双文档工作区

按同日最新反馈调整；此布局替代 `native-unified-ui` 记录中的动态主按钮、可收起右侧参数栏和窄屏上下对照。

## 行为

- 顶部左侧仅保留系统红绿灯，右侧固定添加文件、开始执行、下载三个位置。忙碌时执行位置显示对应取消操作；不可用控件留在原位。
- 选定有效格式后，右侧参数区以 600 毫秒展开。同窗口内重选、移除或清空格式不会自动缩回；未完整选择时显示参数占位提示。
- 导入后切换到三列：左侧缩小的原生玻璃沙漏、文件列表和参数；中间原件；右侧结果。点击小沙漏可回到轮盘，返回本身保留草稿。
- 完成前保留结果空位，完成后直接并排展示。单 PDF 对照优先使用提交时的副本；结果仍通过原有完整性校验。
- 设置固定在右下角，标准菜单和 `⌘,` 仍可用。减少动态效果时取消新增布局动画。
