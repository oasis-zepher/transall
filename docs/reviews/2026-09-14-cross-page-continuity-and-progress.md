# 跨页句衔接与翻译进度

新增跨页接续识别与联合翻译，保留原始区域 ID 和坐标。候选来自相邻页的正文尾部和头部；双栏按右栏页尾到下一页左栏判断，结合标点、字体、正文位置及接续文字，排除短标签、页码、重复页眉、标题和图注。识别出的连字符断词由同一次请求连贯翻译，再按原文含义分别排回原页。

- 链接文字必须完整返回后才合并、保存检查点；缺少半句时重试整组，重试仍缺失则保留此前缓存并停止。后页等待前页衔接完成再进入独立队列，仍最多四页并行，不重复发送同页片段。
- 纯译文模式同样对能可靠判断的页首、页尾进行联合翻译。
- 新增可选 continuationGroup 元数据。旧版缓存仍可读取；重新处理时，只有接续关系发生变化的区域不复用旧翻译，其他区域继续复用。已生成的 PDF 不会自动重译或被覆盖。
- 总进度始终排在最上方，显示实际完整完成的页数；各任务标注当前处理页。总进度和保留版式的页内进度按完成文字量计权，显示复用的完整页数。不用最高已派发页码表示完成页数，也没有添加延时或模拟进度。
- XcodeGen 项目同步纳入新增测试文件。
