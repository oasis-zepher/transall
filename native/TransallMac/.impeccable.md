## Design Context

### Users

Transall serves Simplified Chinese macOS users who need to convert, inspect, OCR, translate, crop, merge, or export documents without learning a technical toolchain. They work with local files and need to understand what will happen before processing starts, whether a task is still running, where a result is stored, and when document text may leave the Mac. The primary job is a short, dependable path from source format to a verified result while preserving the original document.

### Brand Personality

Quiet, precise, trustworthy. The interface should feel like a focused document workbench: calm enough for repeated utility work, exact about task and privacy state, and recognizably native to macOS without looking generic or administrative.

### Aesthetic Direction

Follow the user's latest direction on 2026-09-12: the large format orbit remains the main native App entry. Its center is a single native Liquid Glass hourglass, 168 points high and 34% of the orbit diameter wide (maximum 200). The source chamber stays above the target chamber, with fixed role captions and two native buttons beside the waist: flip to the left and clear to the right at the same height. The former separate reset button is removed. No falling sand or countdown animation. Apply glass to the complete chamber content so the text remains foreground content; do not render the glass above sibling labels. Use one glass shell, with opaque fallback for Reduce Transparency, Increase Contrast and macOS 14–15.

Drag rounded format modules from the circle into either chamber, in either order. Keep click, keyboard, context-menu and VoiceOver alternatives. Occupied chambers support validated replacement, swaps, moves and outside removal; the waist rejects drops. Lifted and selected formats leave the outer ring. Keep the ring's user-chosen circular order for the current window, including while opening and closing the document workspace. Dragging a selected module back toward the ring reserves the chosen gap and inserts it between those circular neighbors, including the last/first gap. Cancelling restores the prior order. Use one persistent visible module per format for the ring, active drag and direct return; keep native glass and label identity through arrival. Keep pointer/keyboard targets as separate clear geometry with no duplicate painted module. Opacity zero is not sufficient to conceal a native glass surface inside a shared glass container. When committing a return, retain the final order locally until the parent binding reflects it, so a stale ring order cannot appear for one frame. Interpolate post-return role colors during settlement. Replaced or cleared formats leave their former chamber along a 960 ms extrusion: source through the top lip, target through the bottom lip; a bulb grows while attached by a narrowing neck, separates at 62% of the animation, then curves to the ring. Only release formats no longer used by either chamber; clearing PDF → PDF returns one PDF module. Render the persistent module visuals outside the hourglass control container to keep labels in front, and retain clear stable gesture hosts inside it. Clear resets the current selection/draft through existing behavior and retains stored results. Disable both controls during active selection motion. Remaining modules redistribute at equal angles along the circumference with a restrained 480 ms ease-out slide. Keep gesture hosts alive until mouse-up without rendering a second glass module. Within the existing 64-point continuous proximity range, a compatible empty or occupied chamber morphs the dragged module into the corresponding full half-hourglass (84 points high) over 780 ms with slight attraction; an incompatible chamber contracts only its width to 85%, without attraction or text/icon scaling. Use a vertical semantic gradient on every module: its upper half represents source compatibility, its lower half output compatibility. Supported halves expose the same native glass as the empty hourglass; unsupported halves use native white/near-black page colors. The opaque supported fallback shares the same system control fill as the hourglass. While a compatible module approaches either chamber, the remaining modules interpolate their role colors toward the validated prospective selection in proportion to docking strength. Leaving or cancelling restores the committed colors; invalid approaches preserve them. Color preview never commits a route or clears a draft. Reduce Motion updates availability without interpolation. Remove the generic “不可用” caption. Supply role-specific help and accessibility values, with top/bottom x-marks for Differentiate Without Color. Departures restore the module over 280 ms; invalid releases return without changing the draft. Morph direction is a signed animated value that passes through the neutral rounded shape when moving between chambers. Animate contour, attraction and release placement from one shared presentation; retain the original 22% gentle attraction during dragging; only place exactly on release, keep the drag preview outside the stationary glass container, and complete the 480 ms ring redistribution before revealing the original gesture host. Render chamber hover highlights over the full 84-point visual half, using the same contour as the morphed module; the 68-point hit region remains separate and must not crop the highlight at the waist. Occupied chambers use the same proximity feedback and atomic compatibility validation as empty ones. Ejected modules emerge through the outer lip as a growing bulb with a narrowing neck, rendered as one native glass silhouette. Keep lateral movement zero until separation. Start the old module’s attached bulge during compatible replacement proximity, continuously up to 50% of extrusion as proximity reaches one. Retreat animates back to zero without touching the draft. During a valid mouse-up settlement, continue toward 60% while still attached. Keep one persistent presentation per format across hover and committed departure; never remove/recreate the bubble or restart from zero. Final departure uses the remaining duration, at least the 480 ms ring redistribution time. Do not prepare ejection for invalid drops, swaps, formats retained in the other chamber, or Reduce Motion. Reveal the icon as the bulb grows and the format name after the small bud stage; do not squeeze text or lift the whole half-hourglass. Complete the rounded module and role gradient during travel to the ring. Reserve the outgoing module at its upper/lower outlet as soon as compatible replacement preparation begins. Keep that same ring plan through mouse-up and departure, and retain the reservation until cancelled extrusion retracts. Any residual clearance rotation is bounded to half one module spacing. Interpolate every module using an unwrapped shortest angular path across the top seam; never search for a hidden gap by rotating the ring through half a turn. Keep the extrusion corridor clear with an 8-point margin. Approaching from the waist ramps feedback through the chamber instead of reaching full strength at the rectangular hit edge. Incoming morph and attached preparation share a 780 ms ease-in-out approach, with 640 ms mouse-up settlement and 280 ms retraction; retain the original 22% attraction. Gray modules remain draggable, but click, keyboard and accessibility assignment must still pass compatibility validation.

Flip only when the reversed selection is supported, including valid single-chamber moves. Disable the control with a specific reason for an empty selection, equal formats, unsupported reverse route, active operation, drag or pending flip. Animate the shell and format positions through 180 degrees over 420 ms while keeping the text upright and role captions fixed. Validate both before and after the animation, publish the selection once, then use new-route defaults with no previous input or preview. Preserve generated job data; never reuse an output as input automatically. Reduce Motion removes rotation, orbit travel, elongation, contraction and attraction, retaining compatibility hints. Keep PDF-to-PDF available through the opposite empty chamber even though PDF has left the ring.

After choosing a route, show the parameter inspector. Importing opens the document workspace, and its toolbar returns to the orbit without discarding the draft. The workspace retains native file navigation, original/result comparison and verified exports.

Use system semantic colors, system fonts and SF Symbols. Follow system light/dark appearance and the user's control accent color (system blue by default). Remove warm green paper, rust accents, decorative grid backgrounds, serif headings, multicolor format nodes and uppercase English section labels.

Liquid Glass is required on macOS 26 for native navigation/toolbars, primary controls and grouped document navigation bars. Use real system glass, never a handmade blur/highlight approximation. Keep documents, text and forms opaque. Provide solid native controls on macOS 14–15 and when Reduce Transparency or Increase Contrast is enabled; honor Reduce Motion.

### Design Principles

1. Make source, target, readiness, progress, failure, and recovery state explicit before adding decoration.
2. Keep document work local by default and describe every network boundary in direct language at the point of use.
3. Preserve user files: never imply success before validating the result, never modify originals, and keep cancellation and cleanup visible.
4. Put document content first. Use the large orbit for format selection, a file sidebar while reading, a parameter inspector, and logs only when requested. Use system semantic colors and shared native control styles.
5. Treat keyboard access, VoiceOver, contrast, larger accessibility text, and reduced motion as release requirements.
6. Optimize for an App Store 1.0 production release: complete interaction states, concise Simplified Chinese copy, native behavior, and no debug-only surface in the shipped app.


## Capability expansion

Keep the five existing task categories and hourglass interaction. Word, PPT and Excel are formats in the same orbit and compact source picker; do not create new task dashboards. The ten-format orbit uses slightly smaller native modules, retaining equal circular spacing and exit clearance. Office conversion is automatic when LibreOffice is installed; one status row in Settings and a contextual missing-component message suffice. Do not add engine selectors or installation wizards. HTML/Markdown printing is offscreen, never an app navigation surface. PDF find/replace belongs in the existing advanced parameters with an accurate modified-page redraw note. Retain draft locks, cancellation, verified previews/exports and old-task decoding.
